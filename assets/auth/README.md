# Entry-screen artwork

AI-generated for Calisync's October 2026 login/onboarding redesign using OpenAI image generation. The four images depict pull-ups, a handstand, parallel-bar dips and gymnastic rings in a dark concrete gym. No third-party stock photography is used.

Images are bundled locally as WebP so the entry screens work without downloading artwork. Text, gradients, branding and controls are native Flutter widgets, not baked into images.
