# Exercise reference illustrations

These app-bundled illustrations are generated artwork, not photographs of users.
They are available offline; viewing them sends no requests to image providers.
They illustrate the named catalog movement, not every trainer-defined variation,
tempo, range-of-motion prescription or individual modification. A trainer should
review the artwork before relying on it as coaching material.

The image mapping uses exact, language-independent exercise slugs in
`lib/data/exercise_illustrations.dart`. Unrecognized/custom labels have no inferred
image. New catalog exercises require an explicit asset and mapping entry.

Generation prompts and source-artifact paths are recorded in `prompts.json`.
